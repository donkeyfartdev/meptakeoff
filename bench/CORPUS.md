# Test corpus

## Status: SYNTHETIC ONLY — no accuracy number may be derived from it

There are **no real MEP plan sets** in this repo. The owner has been asked for
2–3 real multi-sheet sets with known-correct quantities; none have arrived
(risk R10). Until they do, the only test input is a file this repo generates.

| Set | Source | Licence | Sheets | Real? |
|---|---|---|---|---|
| `synthetic_corpus.pdf` | generated by `conduit/bench/make_corpus.py` | this repo | 24 (default) | **No** |

## What the synthetic set is for

It exercises **structure and failure paths**, and nothing else:

* `/Rotate` 0 / 90 / 180 / 270 — the coordinate round-trip test asserts all
  four rotations were actually present, so it cannot pass on unrotated pages;
* MediaBox variety — ARCH D (36×24 in) and ARCH E (48×36 in) landscape;
* vector pages with real text spans and vector paths (title block, legend,
  polyline "runs", a dashed run, a leader line, fixture-ish symbols, a scale
  note and a dimension string);
* flattened-raster pages with **zero** vector text — the "scanned sheet" case
  week 1 records and skips;
* **2 deliberately corrupt pages** — one with `/Contents` pointing at an object
  that is not in the xref, one whose content stream is garbage. Both must raise
  a typed `CorruptPageError` per page while the rest of the run completes.

A `*.manifest.json` is written next to the PDF recording the sha256, page
count, per-page size/rotation/kind, and which pages are corrupt or raster. That
manifest is **structural** ground truth. It contains no quantities, no symbol
labels and no measurements, because none of those would mean anything here.

## What it must never be used for

* Detection precision/recall — the "symbols" are rectangles, not MEP symbols.
* Measurement error — the "runs" are arbitrary polylines with no real system.
* Classification accuracy — the sheet numbers/titles are drawn from an
  eight-entry list and repeat.
* Any number that appears in `bench/RESULTS.md`, a report, or a customer
  conversation.

Throughput and peak-RSS measurements taken on this file are *shaped* like real
measurements but are not representative: the pages are far simpler than a real
sheet. If such numbers are ever recorded, they must be labelled synthetic in
the same line that states them.

Per the roadmap: **when real plan sets arrive, every number measured on
synthetic data is deleted, not carried forward with a caveat.**

## Regenerating

```bash
python -m bench.make_corpus                       # 24 pages -> bench/out/
python -m bench.make_corpus --pages 200           # the roadmap's stress size
```

The default is 24 rather than 200 because `/home` on the development machine is
a 300 MB volume. Generation is deterministic in content but the PDF is not
byte-reproducible (the writer embeds a creation date), so the manifest sha256
identifies a specific generated file, not the generator.

`bench/out/` is git-ignored: the corpus is derived data and is rebuilt in about
a second.
